# Phase 5 Validation Strategy

## Tests
- Teste E2E do pipeline completo (`npm run start` / `npx tsx src/index.ts`).
- Teste do build de produção (`npm run build` e execução via `node dist/index.js`).
- Verificação do arquivo de exemplo `.env.example` e documentação de implantação na VPS.

## Commands
```bash
npm run build
npm run start
```
