## Key Architectural Decisions

- **Tripla Camada de Defesa**: Blacklist rápida no pipeline -> Whitelist no pipeline -> Trava de segurança no Hermes IA.
- **Isolamento de Configuração**: Regras de palavras-chave centralizadas em `src/config/jobFilters.ts` para fácil manutenção futura.
- **Higienização do Banco de Dados**: Possibilidade de rodar purga pontual tanto via API/Script quanto diretamente pela interface da Navbar.
- **Status Automático 'rejected'**: Vagas descartadas não poluem mais o inbox `pending`.
