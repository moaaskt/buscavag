# Scoped Requirements: Buscavag

## User Stories & Functional Requirements

### 1. Coleta de Vagas (Scraping)
- **REQ-SCRAP-01**: O sistema deve coletar vagas publicadas no LinkedIn.
- **REQ-SCRAP-02**: O sistema deve coletar vagas publicadas no Indeed.
- **REQ-SCRAP-03**: O sistema deve coletar vagas publicadas no portal Gupy.
- **REQ-SCRAP-04**: O sistema deve coletar vagas publicadas no Google Jobs.
- **REQ-SCRAP-05**: O sistema deve monitorar grupos e canais do Telegram para extração de mensagens de vagas.

### 2. Filtro Temporal e Deduplicação
- **REQ-FLT-01**: O sistema deve rejeitar vagas cuja data de publicação seja superior a 5 dias.
- **REQ-FLT-02**: O sistema deve persistir as vagas processadas em SQLite para evitar reprocessamento e notificações duplicadas.

### 3. Validação Semântica via IA (Hermes Agent)
- **REQ-IA-01**: O sistema deve integrar-se ao Hermes Agent para analisar o escopo e requisitos da vaga.
- **REQ-IA-02**: A IA deve classificar e aprovar apenas vagas compatíveis com o perfil Dev Full Stack Junior / Jr.

### 4. Notificações via Telegram
- **REQ-NOTIF-01**: O sistema deve enviar alertas formatados para o canal/chat do Telegram do usuário contendo: Título, Empresa, Fonte, Nível, Link Direto e Resumo das Tecnologias.

### 5. Execução Autônoma na VPS
- **REQ-EXEC-01**: O sistema deve ser empacotado em um CLI de execução rápida acionável via Cron/Systemd (2x ao dia).

## Definition of Done (DoD)
- Todos os conectores de scraping funcionando de forma isolada e integrada.
- Deduplicação via SQLite validada em testes.
- Validador IA integrando com sucesso com o Hermes Agent.
- Bot enviando notificações reais no Telegram.
