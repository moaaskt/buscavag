## Key Architectural Decisions

- **Custom DOM Events** para comunicação cross-component sem Context/Zustand
- **`child.unref()`** para que o scraper rode completamente independente do processo Next.js
- **`e.stopPropagation()`** em todos os clicks de ação dos cards para não abrir o modal
- **SweetAlert2** com tema CSS global customizado alinhado ao design system zinc/dark
