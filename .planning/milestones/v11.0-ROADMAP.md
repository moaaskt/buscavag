# Milestone 11: Painel Admin, RBAC e Refatoração de UI

## Overview
Introduz controle de acesso baseado em funções (RBAC), criando um isolamento claro entre visitantes não autenticados, clientes da plataforma e operadores do sistema (Admins). O objetivo alcançado foi limpar a interface do candidato, removendo controles de infraestrutura, e consolidá-los em um novo painel administrativo seguro.

## Phases

### Phase 40: Isolamento de Estado e Limpeza UI Cliente
- Correção da exibição de dados pré-carregados para GUEST.
- Adição de CTAs para `/login` ou `/register`.
- Remoção de controles de infraestrutura do painel B2C.

### Phase 41: Implementação RBAC (Roles)
- Adição da propriedade `role` (GUEST, CANDIDATE, ADMIN) ao modelo de usuário.
- Criação de middlewares e guards para rotas restritas.

### Phase 42: Criação do Painel do Administrador
- Criação da rota isolada `/admin`.
- Migração de botões operacionais e ações de infraestrutura.
- Restrição de APIs operacionais apenas para ADMIN.
